# Обработка изображений: практика 1

Решение задания по цветовым моделям и базовой обработке изображений на снимке SAR (`sar_1_gray.jpg`).

## Что реализовано
1. Загрузка изображения в оттенках серого и построение гистограммы.
2. Гамма-коррекция (γ < 1 и γ > 1) и сравнение с оригиналом по MSE и SSIM.
3. Эквализация гистограммы (собственная реализация, совпадает с `cv2.equalizeHist`).
4. Статистическая цветокоррекция на основе статистики `eq_gray` (собственная реализация).
5. Пороговая фильтрация (Binary, Binary Inv, Trunc, ToZero, ToZero Inv) с разными параметрами, порог Оцу.
